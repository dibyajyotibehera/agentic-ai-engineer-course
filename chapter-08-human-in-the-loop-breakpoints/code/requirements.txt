# Standard library only. There is nothing to install: the durable
# store is SQLite, the webhook endpoint is http.server, and the
# Slack/Teams gates render JSON without any chat account.

# The plan step is a real model call, so the agent run and the demo
# need a configured model backend: set LLM_API_KEY (with
# LLM_BASE_URL and LLM_MODEL as needed) or run with
# LLM_BACKEND=opencheap-connector on a machine where the OpenCheap
# connector is registered. Without a backend the run fails loudly
# instead of planning from a template — this chapter has no mock
# model. The deterministic tests need no backend.
#

# behaviour can be run and tested — the pause, routing and audit
