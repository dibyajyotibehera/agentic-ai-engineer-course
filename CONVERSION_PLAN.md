# Conversion plan: sources and original writing

This file records, chapter by chapter, what was adapted from an existing source and what was written originally, so that the licensing of every part of the course is traceable. The research behind these decisions is in the report that motivated the course (18 November 2026): no existing course covered even half of the twelve topics at advanced depth, so roughly half of this course is adapted material raised to advanced depth, and roughly half is original writing.

## Licence rules applied throughout

- **Microsoft AI Agents for Beginners** (https://github.com/microsoft/ai-agents-for-beginners) is MIT-licensed: its material may be adapted with attribution. Adapted chapters say so in their own `references.md`, and the code samples were re-platformed from the Microsoft Agent Framework and Foundry onto framework-neutral Python unless a chapter genuinely needs a vendor stack.
- **DeepLearning.AI** courses are proprietary: structure and ideas may inspire a lesson, but no content — text, code or diagrams — was copied. Chapters that drew on a DeepLearning.AI syllabus say "inspired by the syllabus of" and link to the course page.
- **LangChain Academy** course content carries no open licence statement: the LangGraph and LangChain frameworks are MIT, but the course prose is not treated as reusable. Chapters that drew on it say "inspired by the syllabus of" and link to the course page.
- **agents-towards-production** is under a custom non-commercial licence: no content from it was reused. It is cited in Chapter 7 only as a pointer for further reading.
- **The Agentic AI Engineer Bootcamp 2026 fork** is a structural template only: its syllabus maps almost one-to-one onto the course's twelve chapters, but only the syllabus file was verified and its content is CC BY-NC 4.0, so no content was taken from it.
- **The LLM course** (https://github.com/mlabonne/llm-course, Apache 2.0) is the style model for the whole repository — chapter shape, hands-on notebooks, references — and is cited as such, not copied from.
- **Anthropic's "Building effective agents"** (https://www.anthropic.com/engineering/building-effective-agents), the **Claude Cookbook** (MIT) and **Google's Agent Development Kit** documentation (Apache 2.0) are cited as references where used; Cookbook recipes and Agent Development Kit code are reusable under their own licences with attribution.

## ByteByteGo gap-fill (Nov 2026)

After the first commit, the three public course outlines of ByteByteGo — AI Engineering Fundamentals, AI Cost Optimization and Build with Claude Code — were checked as a gap list against the chapter texts, and the gaps found were filled with original material. **ByteByteGo's courses are paid and proprietary: no lesson text, code or diagram was copied.** Only the public topic lists were used as a checklist; every explanation, code sample and exercise added here was written fresh in this course's own voice. Each affected chapter's `references.md` cites the relevant ByteByteGo course by name and URL as further reading, with a one-line note that it is a paid live course whose public outline was used as a gap checklist. No chapter was added, renumbered or removed; all additions are sections inside existing chapters.

- **Chapter 02 Tool Use & MCP** — agent skills vs tools (SKILL.md anatomy, composability, skills that call skills); when not to use MCP (per-call token tax, output limits, signal-to-noise); gateway landscape (LiteLLM, Portkey, Kong, Cloudflare, OpenRouter) and observability stacks (Langfuse, LangSmith, Helicone, Arize Phoenix, W&B Weave, Braintrust) as a compact reference section. No new code.
- **Chapter 04 Advanced Memory & Context Engineering** — agentic compaction (/compact-style), tool-result pruning, context rot (attention dilution, behavioural contamination), lazy loading, layers of memory; a one-paragraph RAFT note. New code: `code/compaction.py` + `code/test_compaction.py` (17 tests).
- **Chapter 05 Multi-Agent Swarms & A2A Handoffs** — a short note: subagents (centralised, lower-cost) vs agent teams (peer-to-peer, higher-cost) and when each fits. No new code.
- **Chapter 09 Self-Correction & Reflection Loops** — the biggest addition: runaway-loop taxonomy (retry spirals, ping-pong delegation, oscillation, goal drift, amplification) with detection (counters, state hashing, semantic repetition, progress metrics, watchdog agent pattern); semantic convergence vs stagnation; ReWOO and tree search as named planning patterns; outcome vs process reward models and inference-time scaling for agents (parallel sampling / self-consistency, verifier-guided search). New code: `code/loop_watchdog.py` + `code/test_loop_watchdog.py` (12 tests).
- **Chapter 11 Graceful Degradation & Fallbacks** — cost-aware routing and cascades as a substantial new section (expected-cost formulation, WHEN × SIGNAL × COMPUTE routing framing, predictive vs non-predictive routing, agent-step routing, routing evals: golden sets, replay matrix, shadow scoring, canary); semantic-cache hardening (threshold tuning, failure taxonomy, scoped keys, verifier models, cache-busting anti-patterns). New code: `code/cascade_router.py` + `code/test_cascade_router.py` (11 tests).
- **Chapter 12 Public Agent Teardowns & Portfolios** — distillation as a cost lever (with the staleness-after-a-policy-change trap and retrain trigger); an operating-at-scale section built on the five-pillars framing translated into advanced-level practice; a "rescue a failing agent" capstone exercise variant with a deterministic trace fixture (`code/rescue_fixture.py`, `code/rescue_bundle.json`); cost observability (OpenTelemetry GenAI semantic conventions, attribution hierarchy, cost amplifiers, unit economics per conversation/task) extending `code/cost_per_task.py` with an attribution rollup — the original four-line calculator is untouched and its output verified byte-identical.

## What could not be verified during research

- Whether the bootcamp's claimed 80 tutorials, 20 labs and 15 portfolio projects contain real substance (syllabus file only).
- Lesson-level titles inside DeepLearning.AI's newer long courses (module titles only are public).
- Whether a raw Model Context Protocol server recipe exists in the Claude Cookbook beyond its README table.
- Microsoft Lesson 9's full contents (the research verdict rested on its introduction, learning goals and section headings).
- Hands-on running costs for the Microsoft and Hugging Face courses (Azure account required; some Hugging Face examples use the paid GPT-4o API) — not measured.

Any chapter that repeats one of these claims must mark it as unverified rather than stating it as fact.
